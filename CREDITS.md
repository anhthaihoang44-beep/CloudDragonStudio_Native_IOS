# Credits & Asset Provenance

All code, vector artwork, UI layouts, copy text, and audio assets in **Cloud Dragon Studio** are 100% original creations authored for this project.

- **Artwork & Icons**: Procedural SwiftUI `Shape`/`Path` vector drawings and original Python-generated app icon (`scripts/generate_assets.py`). Zero external sprites or third-party graphics.
- **Audio & Sound Effects**: Procedural `.wav` chimes, water bubbles, brush soft taps, sparkles, and ambient lullaby generated via original synthesis scripts (CC0 / original project assets).
- **Fonts**: Standard Apple system rounded typography (`.rounded` design) with Dynamic Type support.
- **Third-Party Libraries**: None (`0` external Swift packages).
